A custom CRM bringing customer relationships and branch operations into one platform.

**Scope:** contacts and leads, follow-ups, appointments, calls and video calls, calendars, reminders, notifications, notes, user permissions, branch workflows, and reporting.

**Stack:** PHP · MySQL / MariaDB · JavaScript · AJAX · Bootstrap · ApexCharts

### 02 — Economic ScoreBoard · Bonifazi

An internal financial and accounting platform for company and branch operations.

**Scope:** invoices, payments, company and branch expenses, product tracking, financial dashboards, reporting, and business performance monitoring.

**Stack:** PHP · MySQL / MariaDB · JavaScript · AJAX · HTML · CSS

**Stack:** PHP · MySQL / MariaDB · JavaScript · HTML · CSS
